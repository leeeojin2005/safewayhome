# 🛡️ SafeWayHome 
**데이터 기반 안전 귀갓길 안내 및 인프라 시각화 웹 서비스**

<br>

## 💡 프로젝트 소개
**SafeWayHome**은 늦은 밤 시민들의 범죄 불안감을 해소하고 안전한 귀가를 돕기 위해 기획된 **안전 경로 안내 및 인프라 시각화 플랫폼**입니다. 

단순히 최단 거리를 안내하는 기존 지도 앱과 달리, 공공데이터(CCTV, 보안등, 지구대, 안전비상벨 등)를 융합하여 **'가장 안전한 길'**을 직관적으로 보여줍니다. 사용자는 웹 브라우저를 통해 내 주변의 안전 시설물을 한눈에 파악하고, 안심하고 귀가할 수 있는 최적의 정보를 제공받을 수 있습니다.

- **서비스 대상 지역:** 충청남도 천안시 (동남구, 서북구 중심)
- **개발 형태:** Python 및 Streamlit 기반 반응형 웹 애플리케이션

<br>

## ✨ 핵심 기능 (주요 특징)
1. **안전 인프라 종합 지도 (Safety Map)**
   - Folium을 활용하여 천안시 내의 CCTV, 보안등, 안전비상벨, 지구대/파출소 위치를 지도 위에 마커로 시각화합니다.
2. **맞춤형 안전 정보 필터링**
   - 사용자가 원하는 안전 시설(예: CCTV만 보기, 보안등만 보기 등)만 선택하여 지도에 띄워볼 수 있습니다.
3. **위치 기반 안심 정보 제공**
   - 범죄 취약 계층이 야간 이동 시 참고할 수 있도록, 데이터 결측치 및 좌표계 변환이 완벽하게 전처리된 신뢰도 높은 위치 데이터를 제공합니다.

<br>

## 📊 활용 데이터 (공공데이터포털)
본 프로젝트는 다음의 전국 표준 데이터를 수집하여 천안시를 기준으로 필터링 및 전처리하여 사용합니다.
- 📹 **CCTV 위치 데이터:** 전국CCTV표준데이터 (위경도 좌표 기준)
- 💡 **보안등 위치 데이터:** 보안등 표준데이터 (활용 승인 데이터)
- 🚓 **지구대·파출소 위치:** 경찰청 산하 관서 위치 정보
- 🔔 **안전비상벨 위치:** 안전비상벨 표준데이터 (좌표계 변환 완료)

<br>

## 🛠 기술 스택
- **Language:** Python 3.x
- **Web Framework:** Streamlit
- **Map & Visualization:** Folium, Streamlit-Folium
- **Data Processing:** Pandas, Pyproj (좌표계 변환), Requests
- **Version Control:** Git & GitHub

<br>

## 📂 폴더 구조 (Directory Structure)
협업과 유지보수를 위해 데이터를 원본과 가공본으로 분리하여 관리합니다.
```text
safewayhome/
├── data/
│   ├── raw/          # 공공데이터포털에서 다운로드한 원본 CSV (Git 제외 권장)
│   └── processed/    # 결측치 처리 및 천안시 필터링이 완료된 최종 CSV

├── src/              # Streamlit 앱 실행을 위한 실제 파이썬 소스 코드 (app.py 등)
├── outputs/          # 분석 결과물, 캡처 이미지, 추진보고서 등

├── README.md         # 프로젝트 개요 및 실행 가이드
└── requirements.txt  # 필수 라이브러리 목록
